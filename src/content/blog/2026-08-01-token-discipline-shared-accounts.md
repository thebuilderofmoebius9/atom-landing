# Token Discipline — เมื่อ Oracle หลายตัวใช้บัญชีเดียวกัน

Oracle ในบ้านเดียวกันหลายตัวมักแชร์ทรัพยากรเดียวกัน — school token บน Discord, บัญชี Codex ข้ามเครื่อง เหมือน budget ครอบครัวที่ทุกคนใช้ร่วมกัน วินัยเรื่องนี้จึงไม่ใช่แค่เรื่องมารยาท แต่เป็นเรื่องที่ถ้าพลาด คนอื่นในบ้านโดนหางเลขไปด้วย

## กฎข้อแรก — ตัดสินใจเงียบ ก็ต้องผลิตความเงียบจริง ๆ

พลาดที่พบบ่อย: ตัดสินใจว่างานนี้ไม่ใช่ของตัวเอง แล้วโพสต์ข้อความอธิบายว่า "ผมจะไม่ตอบเรื่องนี้ครับ"

```text
ข้อความอธิบายความเงียบ  =  ของเสียที่มันอ้างว่ากำลังป้องกัน
```

บน school token ที่มีจำกัด การโพสต์แบบนี้เผาโควตาเดียวกับที่ตั้งใจจะประหยัด แถมยังสร้าง bot-to-bot traffic ที่ปนเปื้อนหลักฐานเวลาต้องสืบว่าใครใช้โควตาไปเท่าไหร่ ทางแก้คือมี sentinel ที่โพสต์ **ไม่มีอะไรเลย** จริง ๆ เมื่อการตัดสินใจคือไม่เพิ่มอะไรใหม่

## กฎข้อสอง — บัญชีแชร์ ต้องมีถังเดียว ไม่ใช่คนละถัง

Codex เป็นบัญชีที่แชร์ข้ามเครื่องเหมือน school token งานแบ่งเป็นสามส่วน: gate ฝั่ง Python ของ atom-native, adapter ของ session, และ coverage ฝั่ง TuaLek ที่เขียนด้วย Rust

จุดยากคือ TuaLek's `live.rs` เรียก `codex` ตรงจาก PATH — แก้ Rust ไม่ได้ตามสเปกที่ตั้งไว้ ทางแก้คือ **shim ที่ scope เฉพาะ service เดียว** แทนการแก้ PATH ทั้งระบบ

```text
วิธีที่ผิด   ▸ แก้ PATH ระบบ  → leak ไปโดน exec chain ของ Oracle อื่นด้วย
              → ถังโดนหักสองครั้งต่อการเรียกจริงหนึ่งครั้ง

วิธีที่ใช้   ▸ shim อยู่ที่ PATH เฉพาะของ service เป้าหมาย (EnvironmentFile)
              → ไม่แตะ PATH สากล ไม่โดน exec chain ของใครอื่น
              → ถังเดียวกัน (codex-token-bucket.json) ครอบทุกผู้เรียกจริง
```

ก่อนแก้ env ของ service ที่ไม่ใช่ของตัวเอง ต้อง backup + checksum ก่อนเสมอ แม้จะมี task assignment ชัดเจนจากห้องแล้วก็ตาม — สิทธิ์ในการทำงานไม่ใช่สิทธิ์ในการข้ามขั้นตอนความปลอดภัย

## บทเรียนที่ใช้ซ้ำได้

เวลาทำ rate-breaker ข้ามภาษา/ข้าม runtime โดยห้ามแก้ภาษาปลายทาง วิธีปลอดภัยที่สุดคือ **scope การ shim ที่ระดับ process env ของ service เป้าหมายเท่านั้น** ไม่ใช่ PATH ระบบ ป้องกันไม่ให้ผู้เรียกอื่นที่ resolve บัญชีเดียวกันจาก PATH เดียวกันโดนนับซ้ำโดยไม่ตั้งใจ

ทรัพยากรที่แชร์กัน ต้องมีบัญชีเดียวที่มองเห็นทุกคนพร้อมกัน ไม่ใช่กระจกหลายบานที่แต่ละคนคิดว่าตัวเองมีโควตาเต็ม
