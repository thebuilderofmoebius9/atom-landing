# กับดักเหตุผลวนตัวเอง

atom-tab-tab (ตัวสลับหน้าต่างบน macOS) เวอร์ชัน 0.3.2 ผ่านเทสต์ E2E ทั้งหมดด้วย ⌘Tab สังเคราะห์ แต่พอ Axe กดปุ่มจริง ตัวสลับของระบบก็ยังโผล่ ซ้ำสามรอบ

## สาเหตุ

log ของปุ่มจริงแสดงว่าทุก keyDown ของคีย์บอร์ดตัวนี้ติด bit `0x100` (non-coalesced) เสมอ ⌘Tab จริงจึงเป็น `0x100108` ไม่ใช่ `0x100000`

แต่ผมเคยเห็น `0x100` ในอีเวนต์สังเคราะห์ ⌥Tab ที่ตัวเองโพสต์ เลยจัดให้เป็น device bit ของ Option ผลคือทุกปุ่มจริงถูกอ่านว่ากด Option ค้าง และ branch ⌘Tab ที่ห้าม Option ไม่ match เลย

## ทำไมเทสต์ไม่เห็น

ตั้ง mask จากอีเวนต์ที่ตัวเองโพสต์ แล้วทดสอบด้วยอีเวนต์ชุดเดียวกัน จึงผ่านเสมอ ทั้งที่ไม่เคยเป็นตัวแทนของปุ่มจริง

## แก้ที่ราก

ใช้เฉพาะ mask มาตรฐานที่ไม่ขึ้นกับอุปกรณ์: ⌘=`0x100000` ⌥=`0x80000` ⇧=`0x20000` ⌃=`0x40000` fn=`0x800000` ไม่นับ device bit, non-coalesced หรือ numpad เป็น modifier

## กฎ

ก่อนเขียน logic จับคู่อีเวนต์ ให้ instrument → ให้ผู้ใช้กดจริง → อ่านค่าดิบจาก log → แล้วค่อยเขียน ถ้าทดสอบด้วยของที่เราสร้างเอง ต้องมีอย่างน้อยหนึ่งรอบที่ใช้ของจริงเทียบ
