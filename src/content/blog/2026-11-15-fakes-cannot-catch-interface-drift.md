# เขียวทั้งแถบ แต่ของจริงทำงานผิด

ระหว่างพอร์ตบอทจาก Python เป็น TypeScript (atom-native-ts) แต่ละโมดูลมี interface เล็ก ๆ ของตัวเอง (เช่น `AppDiscord`) แล้วเทสต์ parity ใช้ของปลอม (fake) ที่เขียนตาม interface นั้น

ปัญหาคือ interface ในโมดูลกับคลาสจริง (`DiscordClient`) เขียนแยกกัน แล้วเพี้ยนกันได้โดยไม่มีใครรู้:

- โมดูลเรียก `createMessageThread(..., 1440)` แต่ของจริงรับ `{autoArchiveDuration}` ผลคือ thread หมดอายุใน 60 นาที
- โมดูลเรียก `fetchMessages(ch, 12)` แต่ของจริงรับ `{limit}` ผลคือดึงค่าเริ่มต้น 50 ข้อความ

เทสต์เขียวทุกตัว เพราะของปลอมยอมรับอะไรก็ได้ที่ตรงกับ interface ของโมดูลเอง

## วิธีแก้

1. เปิด strict `tsc`
2. เพิ่มไฟล์ `_conformance.ts` ที่มีแต่ type ไม่มี runtime: เอา **คลาสจริง** ไปกำหนดให้ทุก slice interface (ใช้ `Required<>` กับสมาชิกที่เป็น optional)

ถ้า interface กับของจริงไม่ตรงกัน คอมไพล์จะพังทันที ไม่ต้องรอผู้ใช้เจอ

## กฎ

- เทสต์ที่ใช้ของปลอม พิสูจน์ได้แค่ว่าโค้ดเรียกตาม interface ที่เราเขียนเอง ไม่ได้พิสูจน์ว่า interface ตรงกับของจริง
- ตรวจ "ความตรงกัน" ด้วยตัวตรวจชนิด ไม่ใช่ด้วยเทสต์เพิ่ม
