# เทสต์ที่ตรวจเฉพาะ 0 ปล่อยบั๊กเครื่องหมายผ่านได้

การ์ด "ตรวจยอดใช้สิทธิ์" ในหน้าประวัติใบคอร์สฝั่งแอดมินขึ้น ✗ เกือบทุกใบ จนเจ้าของระบบบอกว่า "เตือนทุกอัน" ทั้งที่เทสต์ของการ์ดนี้มีอยู่แล้วและเขียวตลอด

## ต้นตอ

โค้ดเทียบ `usedDeltaSum === pkg.sessions_used` แต่ `package_ledger.delta` เก็บเป็นหน่วย **ครั้งคงเหลือ** (ตอนจองจะเขียน `delta = -1` และ `sessions_used += -delta`) ผลรวม delta ของใบที่ถูกต้องจึงเท่ากับ `-sessions_used` ไม่ใช่ `+sessions_used`

## หลักฐานบรรทัดเดียวที่ชี้ชัด

ยิง SQL กับ D1 โปรดักชัน: 249 ใบ สูตรใหม่ผ่าน 249 สูตรเดิมผ่านแค่ 54 และ 54 ใบนั้นคือใบที่ `sessions_used = 0` พอดีทุกใบ สูตรเดิมผ่านได้เพราะ `0 === -0` เท่านั้น

## บทเรียน

- เทสต์ที่ยืนยัน invariant บนค่า 0 อย่างเดียว คือเทสต์ที่เขียวแต่ตาย
- invariant ที่เป็นสมการต้องมีอย่างน้อยหนึ่งเคสที่ **ทั้งสองข้างไม่เป็นศูนย์**
- พิสูจน์เทสต์ใหม่ด้วยการย้อนสูตรเดิมกลับ: เทสต์ใหม่ต้อง fail (รอบนี้ fail 1 จาก 629 ตามคาด)
- อย่าสรุปว่า "ไม่มีเทสต์คลุม" จาก `grep --include=*.js` เพราะไฟล์เทสต์ `.mjs` จะหลุด ต้อง grep ทั้ง repo ก่อน

“เทสต์ผ่าน” ยังไม่ใช่ done ต้องถามต่อว่าเคสที่ผ่านเป็นเคสที่สูตรผิดได้จริงหรือเปล่า
