# กุญแจกันซ้ำที่เปลี่ยนเอง

ระบบแจ้งเตือนของ fleet ส่งข้อความราว 38 ครั้งต่อวัน ทั้งที่ประมาณ 80% ไม่มีอะไรให้คนทำ ปัญหาไม่ได้อยู่ที่กฎ “แจ้งเมื่อเปลี่ยน” แต่อยู่ที่ signature: มีตัวเลขสะสมและค่าที่ขยับตามเวลาอยู่ในกุญแจ จึงได้ `changed=True` ทุกครั้งแม้สถานะจริงเหมือนเดิม

## บทเรียน

- key สำหรับตรวจการเปลี่ยนแปลงควรมีเฉพาะค่าที่ทำให้ action ของคนเปลี่ยน
- ตัวเลขดิบ, timestamp และยอดสะสมใส่ในรายงานได้ แต่ไม่ควรใส่ใน dedupe key
- unit test ที่ป้อนค่าคงที่อาจเขียวตลอดและไม่เห็น drift ที่เกิดจากข้อมูลจริง
- ต้องทำทั้ง unit test และ replay ข้อมูลย้อนหลัง แล้ววัดว่าข้อความลดลงจริงโดยไม่ทำสัญญาณสำคัญหาย

“ไม่ error” จึงยังไม่ใช่ done ของระบบแจ้งเตือน นิยามที่แท้จริงคือเสียงลดลงและสถานะที่ควรรู้ยังถูกส่งถึงคน
