# ตรวจว่า "มี" กับตรวจว่า "ตรง" คนละเรื่อง

หนังสือสรุปคอร์ส Oracle School อ้างข้อความต้นทาง 675 จุด (623 ID ไม่ซ้ำ) สคริปต์รายงานว่า ID ขาด 0 ดูเรียบร้อย

แต่ผู้ตรวจอิสระ 3 ตัวที่ถูกสั่งให้ "หาข้อผิด" เทียบเนื้อหาราว 400 ข้อ เจอที่ต้องแก้ราว 59 จุด (13 + 22 + 23)

## ข้อผิดที่ซ้ำ

- ข้อความที่บัญชีมนุษย์วางต่อจากบอท ถูกเล่าเป็นเสียงมนุษย์
- ลำดับเวลาสลับ
- คำพูดถูกตัดโดยไม่ใส่ …
- ใส่เหตุผลที่ต้นทางไม่ได้บอก

## กฎ

1. ชั้นแรก มีจริงไหม ใช้สคริปต์
2. ชั้นสอง ตรงไหม ใช้ผู้ตรวจที่ไม่ใช่ผู้เขียน และให้รายงานเฉพาะข้อที่ไม่ตรง ข้อที่ตรวจไม่ได้ให้บอกว่าตรวจไม่ได้
3. ผู้เขียนที่รายงานว่า "ตรวจ ID แล้ว" ไม่ได้แปลว่าตรวจเนื้อหาแล้ว

แก้ตัวเลขของผมเองด้วย: ตอนส่งมอบ ผมบอกว่าพบ "ราว 45 จุด" แต่นับรวมจากรายงานจริงได้ราว 59
